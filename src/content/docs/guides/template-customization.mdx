Standard transactional email triggers often feel generic or rigid. **FormMail Hub's Template & Dynamic Variable Engine** empowers you to create beautifully styled, personalized, and mobile-responsive email notifications and auto-responders that reflect your brand identity.

By utilizing dynamic placeholders, custom HTML/CSS, and automated compliance tags, you can construct targeted communications tailored to each form submission.

---

## 1. Dynamic Tag System Overview

FormMail Hub extracts form responses and system metadata immediately upon submission, mapping them to dynamic tags wrapped in curly brackets: `{Tag Name}`. When an email trigger or broadcast campaign is initiated, these tags are replaced with actual user input or form metadata.

### How Field Mapping Works
- **Form Question Field Tags:** Any question defined in your Google Forms™ automatically becomes a dynamic tag matching the exact question text (e.g., a question titled `"What is your company name?"` becomes `{What is your company name?}`).
- **Case Sensitivity:** Tags are case-insensitive, but maintaining exact matching with your form question labels ensures maximum readability and consistency.
- **Dynamic Resiliency:** If you rename a form question in Google Forms™, FormMail Hub automatically updates internal mappings, keeping active templates functional.

## 2. Dynamic Tag Reference

Below is the verified catalog of dynamic tags supported in FormMail Hub templates:

### Supported Dynamic Tags

| Dynamic Tag | Source Data / Description | Example Output Value |
| :--- | :--- | :--- |
| `{Question Title}` | Dynamically retrieves the answer for the specified form field question. | `Jane Doe` (for field `{First Name}`) |
| `{Form Title}` | The official title of the connected Google Form™. | `Customer Onboarding Intake` |
| `{Unsubscribe link}` | Renders a unique, CAN-SPAM/GDPR compliant opt-out URL (required for campaigns). | `https://hub.formmailhub.com/optout?id=...` |

> **Note on Custom SMTP & Templates:** Admins MUST configure custom SMTP settings before creating email templates, rules, campaigns, or accessing analytics, as these features require sending emails under the Admin's own email identity.

## 3. Visual & HTML Code Editors

FormMail Hub provides two authoring modes for designing email templates:

### Mode A: Rich Text / WYSIWYG Editor
Ideal for non-technical users who want to craft clean, professional emails quickly without touching raw code.
- **Formatting Options:** Bold, italic, underline, list bullets, text alignment, and font coloring.
- **Tag Inserter:** Dropdown menu allowing instant insertion of dynamic tags into the subject line or message body.
- **Link Builder:** Tool for attaching URLs or formatting CTA buttons.

### Mode B: Advanced HTML / Code Editor
Built for developers and marketers who require full custom branding, complex table structures, dark-mode styling, and embedded CSS.
- **Full Control:** Supports standard HTML5 elements (`<div>`, `<table>`, `<img>`, `<a>`, `<span>`).
- **Inline CSS Injection:** Mail client engines (e.g., Outlook, Gmail, Apple Mail) render HTML best when CSS styles are applied inline (e.g., `<td style="color: #1e293b; padding: 12px;">`).
- **Responsive Media Queries:** Support for embedded `<style>` blocks in the `<head>` for responsive email layouts across desktop and mobile devices.

## 4. Step-by-Step Guide: Designing an Onboarding Auto-Responder

Follow these steps to construct a personalized auto-responder email template:

1. Launch **FormMail Hub** in Google Forms™ or Google Sheets™.
2. Ensure Custom SMTP is configured under **Settings > SMTP Config**.
3. Go to **Email Templates** > **+ Create New Template**.
4. Set the **Template Name** (e.g., `Client Onboarding Welcome`).
5. Set the **Email Subject**:
   ```text
   Welcome to {Form Title}, {First Name}!
   ```
6. Switch to the **HTML Code Editor** and paste the responsive HTML layout:

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <style>
    body { font-family: 'Segoe UI', Arial, sans-serif; background-color: #f8fafc; color: #334155; margin: 0; padding: 20px; }
    .card { max-width: 600px; margin: 0 auto; background: #ffffff; border-radius: 8px; border: 1px solid #e2e8f0; overflow: hidden; }
    .header { background-color: #2563eb; color: #ffffff; padding: 24px; text-align: center; }
    .content { padding: 32px; }
    .button { display: inline-block; background-color: #2563eb; color: #ffffff; text-decoration: none; padding: 12px 24px; border-radius: 6px; font-weight: bold; margin-top: 16px; }
    .footer { background-color: #f1f5f9; padding: 16px; text-align: center; font-size: 12px; color: #64748b; }
  </style>
</head>
<body>
  <div class="card">
    <div class="header">
      <h1 style="margin:0; font-size:22px;">Welcome Aboard, {First Name}!</h1>
    </div>
    <div class="content">
      <p>Hello <strong>{First Name} {Last Name}</strong>,</p>
      <p>Thank you for submitting your onboarding intake for <strong>{Company Name}</strong> via {Form Title}.</p>
      
      <p>Our team is currently reviewing your submission details and will follow up shortly.</p>
    </div>
    <div class="footer">
      <p>Sent via FormMail Hub. If you wish to opt out of future emails, <a href="{Unsubscribe link}">click here to unsubscribe</a>.</p>
    </div>
  </div>
</body>
</html>
```

7. Click **Save Template**.
8. Navigate to **Email Rules**, attach this template to your trigger, and select your verified **Custom SMTP** route.

## 5. Testing & Verification Workflows

Before deploying a template to live users, verify variable substitution and layout rendering:

- **Send Test Submission Email:** Click **Send Test Email** in the template editor to dispatch a sample email populated with test or mock question data.
- **Mobile Responsiveness Verification:** Open test emails on both mobile devices and desktop clients (Outlook, Gmail, Apple Mail) to check for proper padding and button scaling.
- **Link & Dynamic Tag Audit:** Click all links in the test email to confirm that dynamic question field tags and compliance links (`{Unsubscribe link}`) resolve correctly.
