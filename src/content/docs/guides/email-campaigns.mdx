While real-time transactional auto-responders deliver single emails upon form completion, **FormMail Hub's Broadcast Campaign Engine** enables Administrators to send targeted bulk communications to collected respondents.

---

## 1. Prerequisites & Platform Constraints

Before launching a broadcast campaign, the following requirements must be met:

1. **Custom SMTP Requirement & UI Lock State:** Admins **MUST** configure and test custom SMTP settings before unlocking Templates, Rules, Campaigns, or Analytics. Until custom SMTP is active, these feature tabs remain strictly locked in the UI.
2. **Google Sheets Add-on Exclusivity:** Bulk sending (Campaigns) is **ONLY** available when launched from the **FormMail Hub Google Sheets add-on**. It is not accessible from Google Forms entry add-ons.

---

## 2. Campaign Creation & Dispatch Workflow

To send a proactive campaign to form respondents, the Admin follows this exact step-by-step workflow:

```

| 1. Admin creates a campaign template                                             |
+-----------------------------------------------------------------------------------+

+-----------------------------------------------------------------------------------+

+-----------------------------------------------------------------------------------+
| 3. Admin enables the rule as an active campaign                                   |
+-----------------------------------------------------------------------------------+
                                          |
                                          v
+-----------------------------------------------------------------------------------+
| 4. Within FormMail Hub Google Sheets add-on interface on responses sheet,        |
|    Admin switches to Campaign view                                                |
+-----------------------------------------------------------------------------------+
                                          |
                                          v
+-----------------------------------------------------------------------------------+
| 5. Admin selects the synchronized campaign name                                  |
+-----------------------------------------------------------------------------------+
                                          |
                                          v
+-----------------------------------------------------------------------------------+
| 6. Admin clicks 'Dispatch' button to initiate bulk email dispatch                |
+-----------------------------------------------------------------------------------+
```

### Detailed Workflow Steps:
1. **Admin creates a campaign template:** The Admin navigates to the template builder, drafts the message content, and saves the template.
2. **Admin configures filtering rules to target respondents in responses Google Sheet:** In rule settings, set targeting criteria against the backing responses Google Sheet™.
3. **Admin enables the rule as an active campaign:** Toggle the rule state to active to synchronize it for campaign dispatch.
4. **Switch to Campaign View:** Within the FormMail Hub Google Sheets add-on interface on the responses sheet, the Admin switches to the **Campaign** view.
5. **Select Synchronized Campaign Name:** The Admin selects the synchronized campaign name from the dropdown list.
6. **Click 'Dispatch':** The Admin clicks the **'Dispatch'** button to initiate the bulk email dispatch processed by the FormMail Hub cloud platform engine.

---

## 3. Compliance & Dynamic Tags

- **Dynamic Tag Accuracy:** Dynamic template tags are strictly handled by the codebase parser. Only dynamic question field tags (e.g., `{Question Title}`) and `{Form Title}` are valid default tags.
- **Opt-Out Handling:** When an opt-out event is processed, the recipient address is flagged and automatically excluded from future campaign dispatches, returning an `OPT_OUT_SKIPPED` log status.

---

## 4. Monitoring Dispatch Performance

Once **Dispatch** is clicked, the Admin can monitor batch processing and analytics within the Google Sheets add-on management client:

- **Delivered Count:** Messages accepted by downstream mail servers.
- **Bounces & Errors:** Tracked via hard (`BOUNCED_HARD`) and soft (`BOUNCED_SOFT`) status codes.
- **Opt-Out Counts:** Total unsubscribes recorded for the campaign run.
