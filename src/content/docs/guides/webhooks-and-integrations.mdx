FormMail Hub is engineered specifically as a dedicated, high-performance email receiving, processing, and dispatching engine for Google Forms™ and Google Sheets™.

This guide outlines the system's core architecture, functional scope boundaries, and the technical design principles governing form response processing.

---

## 1. Core Architectural Scope

FormMail Hub operates strictly as an **email-only notification and campaign automation platform**. All workflows within the application center on processing form submissions and triggering administrative alerts, customer auto-responders, conditional email rules, and broadcast campaigns.

```
+-----------------------------------------------------------------------------------+
|                            Google Form™ Submission                                |
+-----------------------------------------------------------------------------------+
                                          |
                                          v
+-----------------------------------------------------------------------------------+
|                           FormMail Hub Engine                                     |
+-----------------------------------------------------------------------------------+
                                          |
                                          v
+-----------------------------------------------------------------------------------+
|                       EMAIL DISPATCH INFRASTRUCTURE                               |
|                                                                                   |
|  +----------------------------------+    +-------------------------------------+  |
|  | Internal System Notifications    |    | User Custom SMTP Transport          |  |
|  | (Default Admin & Team Alerts)    |    | (Amazon SES, SendGrid, Gmail, etc.) |  |
|  +----------------------------------+    +-------------------------------------+  |
+-----------------------------------------------------------------------------------+
```

### Strict Scope Boundaries

To maintain platform stability, deliverability focus, and data privacy within Google Workspace, FormMail Hub strictly adheres to the following feature boundaries:

- **Email-Only Scope:** FormMail Hub processes form submissions strictly to construct, format, and dispatch emails.
- **No Webhook or HTTP Forwarding Support:** The platform **DOES NOT** support webhooks, HTTP POST payload forwarding, external REST API calls, or custom HTTP notification endpoints.
- **No Third-Party App Integrations:** FormMail Hub does not offer native connectors or data forwarding to third-party messaging or CRM services (such as Slack, Microsoft Teams, Discord, Zapier, Make, or external database APIs).

## 2. Integrated Google Workspace Ecosystem

While external data forwarding is outside the core scope, FormMail Hub provides deep integration across the Google Workspace ecosystem:

### Google Forms Entry Add-ons
FormMail Hub integrates directly within the Google Forms editor through three entry add-ons:
1. **Form Confirmation Emails**
2. **Form to Email**
3. **Form Notifications SMTP**

These entry points allow form creators to configure submission triggers, built-in system notifications, and custom SMTP auto-responders directly where forms are built.

### Google Sheets Core Application
The **FormMail Hub Google Sheets add-on** serves as the core, full-featured application of the ecosystem. It provides:
- **Quota Expansion:** Connecting a spreadsheet enables scaling beyond standard 20-form limits by managing multiple Form Responses tabs within a single connection.
- **Broadcast Campaign Engine:** Bulk email broadcasting to lists of form respondents is enabled exclusively within the Google Sheets core add-on.
- **Audit Logging:** Full diagnostic logs tracking delivery statuses (`DELIVERED`, `BOUNCED_HARD`, `FAILED_SMTP_AUTH`, `OPT_OUT_SKIPPED`) are maintained inside backing spreadsheet tabs.

---

## 3. Security & Data Privacy Advantages

Operating as a self-contained email engine within Google Workspace offers key security advantages:

1. **Zero External Data Storage:** Form responses remain within your organization's Google Forms and Google Sheets infrastructure. Submission payloads are not mirrored or posted to external data collectors.
2. **Reduced Egress Vulnerabilities:** By eliminating third-party webhook forwards, sensitive respondent inputs (PII) are protected from unencrypted HTTP transmission or downstream integration leaks.
3. **Dedicated Transport Infrastructure:** Email transmission relies entirely on Google's internal infrastructure for system alerts or user-authenticated custom SMTP servers (e.g., Amazon SES, SendGrid, Google Workspace) for client-facing outreach.
