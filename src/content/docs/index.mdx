## Architectural Breakdown: 4 Ingestion Bridges & 1 Cloud Platform

FormMail Hub cleanly separates event capture in Google Workspace from backend delivery and state execution:

```
+-----------------------------------------------------------------------------------+
|                        DATA INGESTION BRIDGES (GOOGLE ADD-ONS)                     |
|  +---------------------------+  +-------------------+  +-----------------------+  |
|  | Form Confirmation Emails  |  |   Form to Email   |  | Form Notifications    |  |
|  |     (Forms Add-on)        |  |  (Forms Add-on)   |  |    SMTP (Forms)       |  |
|  +---------------------------+  +-------------------+  +-----------------------+  |
|  +-----------------------------------------------------------------------------+  |
|  |                 FormMail Hub for Google Sheets™ (Add-on)                    |  |
|  |                (Primary Management Client / Campaign Launchpad)            |  |
|  +-----------------------------------------------------------------------------+  |
+------------------------------------------+----------------------------------------+
                                           | Pushes Submission Events & Config Data
                                           v
+-----------------------------------------------------------------------------------+
|                   INDEPENDENT CLOUD PLATFORM ENGINE (EXTERNAL)                    |
|       (High-Performance Event Processing, Rule Evaluation & SMTP Engine)          |
+-----------------------------------------------------------------------------------+
```

### 1. Ingestion Bridges & Scaling
- **3 Google Forms Entry Add-ons:** *Form Confirmation Emails*, *Form to Email*, and *Form Notifications SMTP* act as data ingestion bridges pushing submission events to the cloud engine.
- **1 Google Sheets Management Client:** The *FormMail Hub* Google Sheets add-on acts as the primary full-featured management client. A single spreadsheet can host multiple Form Responses tabs, consuming only **1 connection slot** while scaling across multiple forms and launching bulk email **Campaigns**.

### 2. Dual Delivery Routing Architecture
- **Built-in System SMTP:** Strictly restricted to sending internal system alerts (submission notifications, daily activity reports, and SMTP connection error alerts) to the Form Admin and selected Team Members without consuming your personal email quota.
- **Custom SMTP Relay:** Mandatory for custom email templates, conditional rules, respondent auto-responders, and bulk campaigns. Admins **MUST** configure and test custom SMTP to unlock the UI tabs (*Templates*, *Rules*, *Campaigns*, and *Analytics*).

### 3. Real-Time Attendance & Check-in Engine
- **Duplicate Prevention & 30-Day Retention:** The attendance engine prevents duplicate check-ins and maintains live attendance records with 30-day rolling data retention.
- **Camera & Camera-Free Verification:** Staff can scan visual QR codes with their authorized mobile camera or click direct verification links (`{Verify Link}`) inside notification emails.
- **7-Day Browser Authorization:** Personalized scanner links set a 7-day secure authorization on the user's browser without requiring account logins.

### 4. Multi-Mode Metric Tracking & Daily Reports
- **Multi-Mode Metrics:** Daily tracking of sent emails, delivery failures, and open rates across `system`, `automation`, and `campaign` execution modes.
- **Midnight Summary Reports:** Automated daily reports dispatched at 00:00 (form timezone) via System SMTP to the Form Admin with per-form opt-out capability.

## Dynamic Template Tags Reference

Dynamic tags support `{Tag}`, `{{Tag}}`, and `${Tag}` enclosure formats:

| Dynamic Tag | Purpose & Output | Audience Scope |
| :--- | :--- | :--- |
| `{Question Title}` | Retrieves the submitted answer for any form question field title. | All Templates |
| `{Form title}` | The official title of the connected Google Form™. | All Templates |
| `{All fields}` | Formatted summary table of all form questions and submitted answers. | All Templates |
| `{Linked form}` | Direct URL link to the live Google Form™. | All Templates |
| `{Unsubscribe link}` | Form-specific automated opt-out link for compliance. | Respondent & Campaign Emails |
| `{QR Code}` | Visual QR code ticket image with embedded verification link. | Respondent Tickets, Self-Attendance & Staff Alerts |
| `{Verify Link}` | Direct clickable verification link for instant camera-free check-in on PC/mobile. | Respondent Tickets, Self-Attendance & Staff Alerts |
| `{Check-in Scanner}` | Personalized zero-login staff link for check-in mode (7-day validity). | Staff / Team Emails Only |
| `{Check-out Scanner}` | Personalized zero-login staff link for check-out mode (7-day validity). | Staff / Team Emails Only |
| `{Full Scanner}` | Personalized zero-login link for dual check-in and check-out mode (7-day validity). | Staff Emails & Submitter Self-Attendance |
