---
title: Troubleshooting
description: Fix common FormMail Hub problems with SMTP, missing emails, plan limits, rules, campaigns and QR check-in.
---

Find the message or symptom you see, then follow the fix. If nothing helps, [contact support](https://formmail.vietutd.com/contact) with the form name and the time it happened.

## Emails are not arriving

| Symptom | Fix |
| --- | --- |
| No submission alert | On **Submission Notifications**, check that notifications are on, recipients are ticked, and **Save Configuration** was clicked. Check the spam folder. |
| A team member gets nothing | Their status in **Team Members** must be **Verified**. Use **Resend Email** if the invitation was lost. |
| Respondents get nothing | The rule must use the right **Customer Email Field**, and its conditions must match the answers. Submit a test response that clearly matches. |
| Emails stopped in the middle of the day | You may have reached a [Free plan daily limit](/guides/plans-and-pricing/). Check today's usage on **Analytics**. |
| One person never receives emails | They may have used the unsubscribe link for this form. |

## SMTP

| Message or symptom | Fix |
| --- | --- |
| Test fails with an authentication error | Check the username. For Gmail, use a new 16-character App Password, not your normal password. See [Connect your SMTP](/guides/smtp-setup/). |
| Test times out | Check the host. Use port 587, or 465 if your provider requires SSL. |
| "Your SMTP account uses an API Key. Please enter a verified sender email." | In the rule's **Sender Email**, enter an address verified with your provider (SendGrid, Amazon SES and similar). |
| You receive SMTP error alerts | Your password changed or the provider blocked sending. Update the settings in **SMTP Config** and send a new test. |
| Templates, Rules, Campaigns and Analytics are unavailable | Connect SMTP and send a successful test. |

## Limits

| Message | Fix |
| --- | --- |
| "Quota limit reached: You can only create up to 6 rules on the Free plan." | Delete an unused rule for this form, or upgrade to Pro. |
| "Quota limit reached: You can only create up to 5 email templates on the Free plan." | Delete an unused template for this form, or upgrade to Pro. |
| "Failed to delete the template. It might be linked to an active rule." | Change or delete the rules that use this template first. |

## Rules and campaigns

| Message or symptom | Fix |
| --- | --- |
| "No active team members found." under Internal Recipients | Add team members and wait until they are **Verified**. |
| "No Automation Rules found!" on the Campaigns page | Create the rule for the campaign in **Manage Rules** first. See [Email campaigns](/guides/email-campaigns/). |
| A scheduled email was never sent | The submission arrived after the scheduled time, so it was skipped. |
| A tag appears as plain text | The tag does not match a question title exactly. Copy the title from the form. |

## QR check-in

| Message or symptom | Fix |
| --- | --- |
| "INVALID QR TICKET" | The code is damaged or did not come from this form. Use the link in the guest's email instead. |
| No Check In / Check Out buttons | This browser is not authorized. Open the scanner link again in the same browser. Links opened inside an email app only authorize that app. |
| "Self Check-in Restricted" | The browser was authorized by a different person's link. Each person should use their own links. |
| Check-in refused | The guest is already checked in. Check them out first if needed. |
