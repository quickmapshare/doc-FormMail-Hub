This technical reference details the underlying architecture of **FormMail Hub**, detailing the relationship between Google Forms™ entry add-ons, the core Google Sheets™ application, role permissions, delivery routing layers, and quota expansion mechanics.

## 1. Multi-Addon Ecosystem Overview

FormMail Hub consists of three Google Forms™ entry add-ons and a core Google Sheets™ application:

```
+-----------------------------------------------------------------------------------+
|                             GOOGLE FORMS ENTRY POINTS                             |
|  +---------------------------+  +-------------------+  +-----------------------+  |
|  | Form Confirmation Emails  |  |   Form to Email   |  | Form Notifications    |  |
|  |        (Add-on)           |  |     (Add-on)      |  |     SMTP (Add-on)     |  |
|  +---------------------------+  +-------------------+  +-----------------------+  |
+------------------------------------------+----------------------------------------+
                                           |
                                           v
+-----------------------------------------------------------------------------------+
|                             CORE APPLICATION HUB                                  |
|                     FormMail Hub for Google Sheets™ Add-on                        |
|                  (Full-Featured Application & Engine Layer)                       |
+-----------------------------------------------------------------------------------+
```

### Core Application vs. Entry Add-ons
- **Full-Featured Core Application ("FormMail Hub" Google Sheets Add-on):** The main application of the ecosystem. Manages lead index datasets, hosts campaign batch execution, executes bulk email broadcasts, and provides full diagnostic logs.
- **Google Forms Entry Add-ons:** Three Google Forms add-ons (*Form Confirmation Emails*, *Form to Email*, and *Form Notifications SMTP*) provide entry points directly within the Google Forms editor for real-time submission triggers.

### Form Quota Expansion via Google Sheets
Standard configurations enforce limits on the number of connected forms (typically 20 forms). Connecting a spreadsheet via the **'FormMail Hub' Google Sheets add-on** enables scaling beyond the standard 20-form limit, because a single spreadsheet can contain multiple Form Responses tabs while using only one active connection.

## 2. Roles & Permissions Architecture

FormMail Hub enforces strict role boundaries:

- **Primary Connector / Admin Role:** Only the **first user among the form's editors who connects that form to FormMail Hub** is granted exclusive rights to configure settings, templates, rules, custom SMTP, and triggers for that form.
- **Team Member Logic:** Team members are **ONLY** added so the Admin can select who receives email notifications upon form submission. Team members **DO NOT** have edit or configuration permissions.

## 5. Campaign Creation & Dispatch Workflow

Bulk email marketing dispatches follow a strict execution sequence in the core Google Sheets add-on:

1. **Template Creation:** Admin creates a campaign template containing required `{Unsubscribe link}` compliance tags.
2. **Rule Configuration:** Admin configures filtering rules to target specific respondents in the responses Google Sheet™.
3. **Rule Activation:** Admin enables the rule as an active campaign.
4. **Interface Navigation:** Within the FormMail Hub Google Sheets add-on interface on the responses sheet, Admin switches to the **Campaign** view.
5. **Campaign Selection:** Admin selects the synchronized campaign name from the campaign list.
6. **Dispatch Execution:** Admin clicks the **'Dispatch'** button to initiate the bulk email dispatch.
